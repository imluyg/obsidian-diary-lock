# 日记锁（Diary Lock）

给 Obsidian 的日记加一把"日期锁"：**过去的日记打开就是只读，今天的照常写。**

默认跟着 Obsidian 自带的「日记」核心插件走——文件夹和日期格式都从那里读，装到任何库里都不用先改配置。

## 安装

**方式一：克隆到插件目录**

```bash
git clone https://github.com/imluyg/obsidian-diary-lock "<你的库>/.obsidian/plugins/diary-lock"
```

**方式二：用 Release**

从 [Releases](https://github.com/imluyg/obsidian-diary-lock/releases) 下载 `manifest.json`、`main.js`、`styles.css`，放进 `<你的库>/.obsidian/plugins/diary-lock/`。

装好后重启 Obsidian，在 设置 → 第三方插件 里启用「日记锁」。

## 它做什么

- 日记文件夹里、路径能按日期格式解析出来的笔记（比如 `2026-11-02`、`2026/11/2026-11-02`），**只要不是今天**，打开时进入阅读视图，状态栏显示 `🔒 已锁定`。
- **打开时不弹任何窗口**，安静地以只读方式打开。只有你主动去编辑（点铅笔或按 `Ctrl+E`）时，才会退回阅读视图，并用一条短提示说明怎么解锁——同一篇只提示一次，之后静默退回。
- `Ctrl/Cmd+E` 在锁定的日记里会被直接拦掉，不依赖 Obsidian 的模式切换事件。
- 想改的时候：点状态栏的锁、侧边栏的锁图标，或按命令面板里的「锁定 / 解锁当前日记」，这时才弹确认框。确认后只对**当前标签页**解锁：在这个标签页里换到别的日记、或关掉标签页，就会重新上锁。
- 补充当天的感受不用解锁：命令「追加一条日记」（或侧边栏铅笔图标）会打开一个小输入框，把一行内容写到指定标题所在小节的末尾，**不碰任何已有行**。
- **属性（frontmatter）也锁住了**：阅读视图顶部的「属性」块点不动；万一还是被改了（别的插件、命令、外部工具），写盘后会立刻还原成锁定时的样子，正文不受影响。

## 配置

设置 → 第三方插件 → 日记锁。

| 设置项 | 说明 |
| --- | --- |
| 日记文件夹 | 留空 = 用「日记」核心插件里的文件夹 |
| 日期格式 | 留空 = 用「日记」核心插件里的格式；也可手填 `YYYY-MM-DD`、`YYYY/MM/DD`、`YYYY/MM/YYYY-MM-DD` 等 |
| 追加位置标题 | 「追加一条」插到这个标题小节的末尾；留空 = 直接追加到文末 |
| 追加条目格式 | `{time}` 替换成当前时间，默认 `- {time} ` 得到 `- 08:30 内容` |
| 锁定过去的日记 | 总开关 |
| 解锁时二次确认 | 只在主动解锁时弹框，打开笔记不弹 |
| 尝试编辑时提示一次 | 关掉后连那条短提示都没有 |
| 保护笔记属性 | 锁定时改 frontmatter 会被还原 |
| 状态栏图标 | 右下角 `🔒` / `🔓`，点击可锁定或解锁（手机上用侧边栏的锁图标） |

## 为什么不在保存时检查

Obsidian 在编辑模式下敲一个字符就立刻写盘，没有"确认保存"这一步。所以锁只能在**进入编辑之前**拦——这也是"切回编辑就退回阅读视图"的原因。

## 已知限制

- 点铅笔按钮进入编辑这条路径依赖 Obsidian 的 `layout-change` 事件；`Ctrl/Cmd+E` 由按键拦截，不依赖它。
- 只挡"在 Obsidian 里写"，挡不住别的程序直接改盘上的文件；也不管删文件和重命名。
- 正文没有自动还原。这是刻意的：如果开启了同步，手机端解锁编辑后同步回来，自动还原会把它当成篡改，反而丢数据。
- 界面文案目前是中文。
